## Use it on your model
1. Copy `LICENSE.md` into your repo as `LICENSE`, unchanged.
2. Add a `NOTICE` file:
   ```
   <Model name> is licensed under the Velandris License 1.0.
   Licensor: <your name>
   Attribution: "Built on <Model name> by <your name>"
   Governing law: <your jurisdiction>          (optional; default Hong Kong SAR)
   Third-party components: <name, license>     (if any)
   ```
3. On Hugging Face, put this in your model card's YAML header:
   ```yaml
   license: other
   license_name: velandris
   license_link: https://huggingface.co/Velandris/velandris-license/blob/main/LICENSE.md
   ```
